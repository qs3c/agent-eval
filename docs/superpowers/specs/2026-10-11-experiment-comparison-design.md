# 实验内多 Agent 对比

用户已在聊天确认本设计，2026-10-11。沿用已有实验、报告和原生轨迹，不启动模型实验。

- 主入口选一个实验，显示所有配置 Agent 在全部选定任务上的整体表现和逐题矩阵；只选一题也适用。
- SWE 采用 resolved 语义；每题先平均固定次数的尝试，再等权平均任务。任务缺失、异常、未评分不从分母删除。完整评分之前只显示暂定已解决占计划比例，不冒充最终成绩。非二值主指标保留原单位。
- 输入/输出 Token、Agent 执行时间、已知费用独立展示，并显示已记录覆盖次数；未知总量不填零。不同 Agent 的同一道题可展开独立尝试，复用已有补丁、测试与轨迹卡。
- 数据集名称、修订、split 与评分器/环境版本为可选严格配置，随冻结配置持久化。旧实验缺失信息显示未知；根据冻结 SWE 任务证据识别旧 resolved 语义，不捏造版本。
- 跨实验保留为辅助入口，检查版本、任务内容、模型与资源条件；已声明数据集而修订不明时不声称可直接配对。
- 主分依据现有 Harbor 内置评分，和人工复核/官方独立复评分开。mock、offline、诊断和待复核标签始终可见。

实现边界：新增一个纯统计模块及只读 comparison API，复用 detail 的原始结果读取；前端新增总览组件，复用 traceCard。现有结果不回写、不重跑、不自动拼接多个实验。
