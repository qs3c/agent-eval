# 公共平台与用户项目隔离

公共源码只提供 DSH、OpenCode、Hermes 的内置配方和执行器入口。个人被测项目的源码、专用适配器、部署地址、实验配置、诊断材料和复核记录不作为公共示例分发。

用户通过标准配方导入自己的 Agent；源码位置和目标检查命令由用户的 `rsi-profiles/<agent-id>.json` 显式配置。该目录下的 `.json` 配置、`.workspace/`、`.rsi/`、`.console/`、`artifacts/` 与访谈材料均应保留在本地，不提交公共 Git 仓库。

本次迁移先在仓库外备份相关文件，再移出私人专用实现与配置。旧项目验证报告不改写成公共 Agent 的成绩。历史实验原始 evidence 保留；本地轨迹复核信息使用 `.console/trace-reviews.json`，读取器仍兼容旧的 `console_reviews.json`。

旧实验若引用已移出的专用适配器，不能直接用新平台重跑。应保留匹配的旧版本环境只读查看历史，或由用户提供自己的适配器/标准配方，重新构建 Release 并验收；不要覆盖冻结 manifest 或用新产物冒充原版本。

清理当前工作树不等于清理 Git 历史。已有 commit、远端分支和缓存可能仍含旧材料；公开发布前需另行决定历史迁移或新建干净仓库。这次改动不自动改写历史、推送或部署。
