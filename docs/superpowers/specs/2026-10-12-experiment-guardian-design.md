# 实验运行守护

用户已在聊天确认设计并授权实施。首个守护 Agent 不指定，使用可插拔协议。

固定程序发现异常并先保存现场；守护 Agent 自主调查和直接使用工具处理；平台记录实际操作并提供独立期限兜底。恢复步骤不使用故障类型到动作的固定映射。

## 边界

- 不修改历史实验，不重跑付费模型实验，不替换线上 BKCrab。
- 显式配置 guardian 后启用。未配置时保持现有 Harbor Job 执行。
- 开启守护时每个尝试用独立 Harbor Trial 工作进程，父进程负责并发、监测和有界清理，避免卡死的 Trial 阻塞后续任务。
- Linux + Docker 为执行目标；非 Linux 启用守护时明确拒绝。
- 生命周期钩子保存阶段与结果快照。监测使用阶段期限、工具调用/返回和日志进展；静默只触发调查，不直接证明死锁。
- 初始现场保存在宿主机，包含触发信息、有限日志尾部、容器状态和进程/文件描述符；部分采集失败必须保留错误。
- 守护插件为可信的命令行适配器，通过 JSONL stdin/stdout 接收现场，直接调用 snapshot/exec/finish 工具。exec 是目标容器内任意 shell，不是预定义修复菜单。每次调用与结果由父进程留证。
- 没有插件时执行观察与期限兜底；不宣称完成了模型诊断。
- 工具超时、守护超时和 trial 总期限独立；守护不能延长原 Agent 阶段期限。
- 干预动作执行前保存标记；操作前重新确认容器身份。正常 Agent 阶段结束后撤销恢复操作资格。
- 初始/后续快照与处理总结分开，实际进展才是恢复证据。无法恢复时保留失败并继续后续任务；Docker 不可用时不谎称资源已释放。
- 外部辅助与原始成绩并列记录；不改变评分，不把辅助成功当作自主成功。
- UI 展示事件与受辅助标记；运行协议和样例写入文档。源码修复、PR 和多代搜索属于后续 RSI 子项目。

## 验收

配置兼容；正常长任务不误杀；失联插件有界退出；任意 shell 操作自动留痕；进展验证不能由插件一句 recovered 取代；目标身份变更不继续执行；取证失败不阻断兜底；一题卡死后下一题完成；原始结果不覆盖；页面可读取事件且不暴露私有原始推理日志。
