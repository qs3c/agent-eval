# 有界批次测评

用户已确认：一个实验每批最多 20 题，两个 Agent 都完成该批和官方复评后清理，再进入下一批；异常现场有限保留。

- 80 题名单及排除的 21 题保持不变；并发 2、assist、40 轮/600 秒守护预算不变。
- 题目元数据和 Agent 产物先冻结；镜像只按当前批拉取。共享评分 archive 在每个冻结目录独立保存一份，各题使用硬链接。
- 批次状态为 preparing / running / regrading / cleaning / completed，失败和中断状态可见。显式 resume 跳过已有有效结果，不偷偷重跑失败尝试；不确定的残留尝试拒绝自动重跑。
- 先校验并保存每题 native logs、patch、verifier 输出、守护操作和 provenance；官方复评限定当前批题目，保留全部原始报告。
- 正常执行且证据齐全的题清理，包括 reward=0。异常、外部辅助或证据缺失先保留停止状态容器/诊断材料；默认最多 3 个、20 GiB、24 小时。
- 清理只处理精确记录的批次镜像/容器；受其他容器引用时保留并记录原因。构建缓存仅删除未使用缓存，不清生产镜像、数据卷或历史实验产物。
- 实验详情展示批次状态。整体验证包括调度顺序、中断恢复、共享文件独立性、异常保留、容器引用保护及 Docker 正/负对照。

边界：停止容器保留文件系统，无法保留进程内存；磁盘实际余量仍受单题镜像大小影响，20 是数量上限而非固定空间保证。
