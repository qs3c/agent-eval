# RSI Implementation Plan

Execute inline in the current authorized session. Use the approved design at `docs/superpowers/specs/2026-10-12-rsi-design.md`.

Goal: evidence → isolated source improvement → checks → paired eval → draft PR, with durable candidate lineage and pluggable execution.

## Files and interfaces

- `rsi/models.py`: strict Profile/Adapter/Command contracts, trusted profile loading.
- `rsi/evidence.py`: `create_case(store, run, agent, trials, objective)` freezes bounded evidence and a provenance index.
- `rsi/store.py`: persisted cases/candidates/action queue, `enqueue`, locking and recovery. Never auto-resume interrupted execution.
- `rsi/process.py`, `rsi/git.py`: bounded commands, independent clones, exact commits and clean-source checks.
- `rsi/runner.py`: `improve`, `evaluate`, `publish`, `perform`; structured adapter context and result, phase persistence, PR body.
- `rsi/evaluation.py`: paired-build/re-evaluation and comparison of complete reports and frozen task identity.
- `rsi/api.py`, `static/rsi.js`: trusted profiles, case creation from registered completed runs, queue actions and archive/detail views.
- `cli.py`, `console.py`, `web.py`, `static/app.js`, `static/index.html`: command registration, existing worker integration, routes/navigation.
- `tests/test_rsi.py`, `tests/test_rsi_web.py`, `tests/test_rsi_docker.py`: unit, actual Git/process, web and opt-in Harbor acceptance.
- `docs/rsi.md`, `rsi-profiles/bkcrab.json.example`: interface, operator setup, limitations and example without a selected model.

## Steps

- [x] Evidence/store: test exact exports and missing/truncated records; immutable IDs and safe lookup; implement atomic records and action locking.
- [x] Adapter/improvement: temporary Git fixture with broken function; driver repairs it, writes cited diagnosis; platform commits, tests and preserves source checkout. Test timeout, invalid citation, failed check and invalid parent.

- [x] Product: queue actions from console/CLI, interruption state, read-only evidence indices, RSI navigation and details; test that web cannot supply commands or arbitrary paths.

- [x] Document observed results and remaining configuration requirements, commit the implementation.

No external publication, paid model selection, automatic merge or production BKCrab replacement is required to validate this implementation.
